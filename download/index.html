The editor comes with the command-line tools beside it: Tools.Cook, Tools.Export and Tools.Mcp, the MCP host for agents.

Export templates

The players a game exports onto. Unpack one, then add it in the editor with Edit, Export Templates, Install from Folder.

  • Windows playerDeploymentTemplate-0.1.0-beta.3-Win64.zip
  • Linux playerDeploymentTemplate-0.1.0-beta.3-Linux64.tar.gz
  • Web player (WebAssembly with WebGPU)DeploymentTemplate-0.1.0-beta.3-Web.tar.gz

Every release, with its debug symbols and the sample projects, is on GitHub.

Requirements

  • Windows or Linux, 64-bit (x64).
  • A GPU that runs Vulkan 1.3, or Direct3D 12 on Windows.
  • For web exports, a browser with WebGPU: a recent Chrome or Edge.

From source

The engine builds with CMake and Ninja, using Clang or GCC on Linux and Clang or MSVC on Windows.

Problems

Ask in the Discord, or open an issue on GitHub. Put the editor's version in it: Help, About, then Copy Version.

AssiduousEngine is a game engine in C++23, with its editor, asset pipeline and tools.

The engine is MIT licensed. The AssiduousEngine name and logo are not.
