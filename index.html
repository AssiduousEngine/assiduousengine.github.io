Open-source game engine and editor

AssiduousEngine is a C++23 game engine and editor, built entirely with C++ modules. Its editor, asset pipeline, runtime and tools work together, with modern rendering, gameplay scripting and a full UI framework. AI agents can use it too, to build whole games from an empty project to a playable build.

Highlights

Rendering

Forward PBR on a render graph

Clustered lights, cascaded and local shadows, image-based lighting and a full post stack, on Vulkan, Direct3D 12 and WebGPU.

More about rendering

Custom shaders

Your own shaders, previewed as you type

Write HLSL in the editor and see it on a preview as you edit. It runs on the web too, cross-compiled to WGSL.

More about custom shaders

Networking

Multiplayer built in

Components replicate their marked properties with no network code of their own, and a desktop host takes browser players over WebSocket.

More about networking

UI

Game screens in markup and CSS

Layouts, styles, animation and gamepad navigation for menus and HUDs. The editor itself is built with it.

More about ui

Agents

Build a game with an AI agent

Connect an agent such as Claude Code over MCP, and it can take a game from an empty project to an exported build: create the project, import assets, build scenes, write scripts and shaders, lay out UI screens, playtest the game and export it.

It works in the editor you have open. Its scene edits go through undo like yours, it checks its work through screenshots, and the editor's MCP panel lists every call it makes.

Every sample game was developed this way, start to finish, by an agent working through the MCP tools.

How agents work with it
# Wire Claude Code to the editor's MCP host
claude mcp add --transport http assiduousengine-editor \
  http://127.0.0.1:7405/mcp \
  --header "Authorization: Bearer $TOKEN"

# The editor's MCP panel copies this line, token and all.
